# 🐫 Arabian Wildlife Detection using YOLOv11

An end-to-end Computer Vision project designed to detect and classify native wildlife in the Arabian Peninsula using custom transfer learning pipelines. This repository covers automated data collection, auto-labeling, dataset preparation, and deep learning model training using Ultralytics YOLOv11.

---

## 📌 Target Species

* **Arabian Oryx** (*Oryx leucoryx*)
* **Reem Gazelle / Sand Gazelle** (*Gazella marica*)
---

## 🛠️ Tech Stack & Libraries

* **Framework:** PyTorch & Ultralytics YOLOv11 (`yolo11m`)
* **Data Fetching:** `pyinaturalist` (iNaturalist API integration)
* **Auto-Labeling:** Autodistill & Grounding DINO
* **Computer Vision & Visualization:** OpenCV, Matplotlib, PIL
* **Environment:** Kaggle Notebooks (GPU P100 / T4)

---

## 🚀 Pipeline Overview


Data Collection (iNaturalist) ➡️ Auto-Labeling (Grounding DINO) ➡️ Dataset Splitting & Formatting ➡️ Transfer Learning (YOLOv11m) ➡️ Performance Evaluation
1. Automated Data Collection
Image datasets were fetched dynamically using the pyinaturalist Python SDK, pulling research-grade observation photos for target species taxonomy IDs.

2. Zero-Shot Auto-Labeling
Instead of manual annotation, bounding boxes were generated using Grounding DINO via Autodistill with class-specific text prompts:

Arabian Oryx: "white oryx with long straight horns"

Reem Gazelle: "sand gazelle"

To prevent cross-annotation errors, images were organized into species-specific subdirectories during the labeling phase before being merged into the final YOLO format.


⚙️ Model Training & Hyperparameters
Transfer learning was performed using YOLOv11m (yolo11m.pt) fine-tuned over 100 epochs with frozen backbone layers (freeze=10) to preserve low-level features while adapting detection heads to desert environments.

```Python
from ultralytics import YOLO

model = YOLO('yolo11m.pt')

results = model.train(
    data='/kaggle/working/corrected_data.yaml',
    epochs=100,
    imgsz=640,
    batch=16,
    freeze=10,
    project='/kaggle/working/runs',
    name='desert_wildlife',
    iou=0.45,
    single_cls=False
)
```

📈 Performance & Results
The trained model achieved high accuracy and localization precision on the validation split:

mAP@0.50: ~88% - 90%

mAP@0.50:0.95: ~74% - 76%

Convergence: Loss curves show smooth convergence with no signs of overfitting beyond epoch 10.

💻 How to Run Inference
To test predictions using the trained weights (best.pt):

```Python
from ultralytics import YOLO

# Load trained weights
model = YOLO('path/to/best.pt')

# Run inference on a test image
results = model.predict(
    source='test_desert_image.jpg',
    conf=0.30,
    save=True
)
```
# Process results
```python
import matplotlib.pyplot as plt
import cv2
import glob
import os

# Find the latest prediction folder generated by YOLO
latest_predict_dir = max(glob.glob('/kaggle/working/runs/detect/predict*'), key=os.path.getmtime)
predicted_images = glob.glob(f"{latest_predict_dir}/*.jpg")

if predicted_images:
    # Read the first predicted image
    img_path = predicted_images[0]
    img = cv2.imread(img_path)
    
    # OpenCV loads images in BGR format, convert to RGB for matplotlib
    img_rgb = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)
    
    # Plot using matplotlib
    plt.figure(figsize=(10, 10))
    plt.imshow(img_rgb)
    plt.axis('off')
    plt.show()
else:
    print("No prediction images found yet. Make sure to run model(source=...) first!")
```
